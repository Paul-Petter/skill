一、平台定位
蓝鲸 PaaS（也称蓝鲸工具 PaaS 平台、蓝鲸集成平台）是承载腾讯游戏运营系统和支撑工具的 PaaS 平台，面向开发者提供一站式应用开发能力。其设计参考了 PaaS 平台鼻祖 Heroku，核心要素包括：以“源码仓库”为核心、使用各编程语言的开源 buildpack 将源码构建为产物、通过 Procfile 文件定义应用进程等。平台的目标是让开发者免于运维与基础设施工作，专注于 SaaS 开发。

二、核心能力
1. 开发者中心

蓝鲸开发者中心是一个开放式的 PaaS 平台，从应用创建、部署到后续维护管理，提供自助化与自动化服务，并配套运营数据分析、性能监控等周边能力。主要功能包括：

应用注册与基本信息管理（自动分配 DB 资源、代码仓库资源、SVN 权限）

应用角色管理（创建者、开发者、管理员）

应用发布部署及下架（支持测试环境与正式环境、版本控制、评审机制）

应用日志管理（统一格式与目录规范，统一收集）

应用监控和告警

应用数据库管理、代码管理、数据分析

自定义环境变量、应用权限控制（用户与 IP 限制）

2. 开发框架

平台提供统一的开发框架与规范，支持 Python、Go、Node.JS 等编程语言，也支持前后端工程分离（前端可选 Vue 开发框架，后端可选 Python 或 Golang 框架）。早期还曾推出 PHP 版开发框架（基于 Laravel）。

3. 多模块能力

多模块功能支持将应用按功能拆分，各模块绑定独立的源码仓库与增强服务，可独立开发、部署，适用于前后端分离以及微服务架构实践。

4. 应用模型与云原生应用

平台推出了新的 SaaS 类型——云原生应用，其核心是“应用模型”：一套描述蓝鲸 SaaS 的标准，允许开发者用一个 YAML 文件完全定义 SaaS。应用模型采用 Kubernetes API 规范，引入 BkApp 资源抽象，并配套表单式“应用模型设计器”。云原生应用支持镜像部署与源码部署两种方式，也支持使用平台原有的增强服务、日志查询、独立域名等能力。

三、演进历程（据材料时间线）
PaaS 3.0：基于 BCS（蓝鲸容器服务）原生 Kubernetes 进行微服务实践，将托管应用从原生 docker 部署升级为 Kubernetes 集群统一编排管理，利用服务发现、滚动更新、资源调度等特性提供更优质的服务。

应用模型（2022 年）：推出“应用模型”，推动平台重心从“基于源码的构建与发布流程”转向“基于描述型语言的应用模型”。

云原生应用（2024 年）：提供更贴近 Kubernetes 的云原生部署体验，支持镜像部署与源码构建镜像（蓝鲸 Buildpack / Dockerfile）。
